# Tejal Mugul — Healthcare Operations Analytics Dashboard

An original Excel analytics case study demonstrating how operational healthcare data can be translated into management-ready KPIs, service-performance insights and improvement opportunities.

## Business question

How can an emergency-care operation use patient-flow and service data to understand demand, timeliness, utilization and patient experience?

## Analysis framework

**Demand → Flow → Timeliness → Outcomes → Patient Experience → Improvement Opportunities**

### Core KPI areas
- Patient volume
- Average waiting time
- Patient satisfaction
- Timeliness of care
- Admission vs. non-admission
- Age-group distribution
- Gender mix
- Department/referral patterns
- Month-level trends

## Consultant lens

Rather than treating the workbook as only an Excel dashboard, the analysis focuses on:
1. identifying operational bottlenecks,
2. comparing service performance across periods and patient segments,
3. connecting operational metrics with patient experience,
4. translating the findings into management actions.

## Excel methods

- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Formula-driven summaries
- KPI cards
- Interactive filtering

## Deliverables

- Management-style Excel dashboard
- Structured KPI framework
- Operational interpretation
- Improvement-opportunity view
