# Source Workflow Reference

This folder documents the component structure of the public reference project used as inspiration for the Tejal Mugul implementation.

The Tejal project uses original code, prompts, scoring criteria and workflow design adapted to Tejal's professional profile. No source author's credentials, private data, or private session information are included.

Reference components reviewed:
- Deduplication logic
- Deterministic role filtering
- AI job-matching prompt
- Workflow orchestration JSON
- Output screenshots

The working Tejal implementation lives in the parent project folder.
