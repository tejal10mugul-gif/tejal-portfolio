# Tejal Mugul — AI Job Intelligence & Opportunity Prioritization

An original portfolio project demonstrating how I apply **market research, competitive intelligence, business analysis, automation and AI-assisted evaluation** to improve job-market research.

## Business problem

Job searching creates a noisy research problem: hundreds of openings can be discovered across job boards, company career pages and professional networks, but only a small subset is relevant to a candidate's target role, experience, location and skills.

This project turns that problem into a repeatable intelligence workflow:

**Discover → Clean → Validate → Match → Score → Prioritize → Review**

## Workflow

1. **Opportunity discovery** — collect recent opportunities from permitted public sources and company career pages.
2. **Normalization** — standardize title, company, location, experience, source and application URL.
3. **Quality checks** — remove duplicates, stale records and obvious non-hiring/promotional content.
4. **Profile matching** — compare role requirements with my skills, experience and target positioning.
5. **AI-assisted classification** — summarize fit, identify strong keywords, missing requirements and risks.
6. **Priority score** — rank opportunities for manual review.
7. **Application intelligence** — capture hiring contact, source, application route and follow-up notes when available.
8. **Human decision** — I review the opportunity before applying. The system does not submit applications automatically.

## Scoring framework

| Dimension | Weight |
|---|---:|
| Role / function fit | 25 |
| Skill alignment | 20 |
| Experience fit | 15 |
| Industry / consulting relevance | 15 |
| Location / work model | 10 |
| Source / application quality | 10 |
| Recency | 5 |
| **Total** | **100** |

### Priority

- **85–100:** Priority application
- **70–84:** Strong match
- **55–69:** Review if strategically useful
- **Below 55:** Low priority

## Technology concept

## Responsible automation

This is an **assistive research system**, not an auto-apply bot. Credentials, private data and platform session information are never stored in the repository. External platform terms and applicable usage policies must be followed.
